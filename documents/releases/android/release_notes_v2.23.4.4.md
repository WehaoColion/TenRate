# Android 2.23.4.4 Agent 任务助手移动端 UX 改进候选

## 目标与范围

仅调整 Android 端的 Agent 发起、资料选择、核对与运行状态界面。继续由 Rust 源生成器负责界面修改，不改 Windows 客户端、数据格式、同步协议、模型请求工具链、实际授权范围或保存校验。

## 具体变化

1. 从知识页打开任务助手时，将当前页面预先列入本地选择清单。只是在界面中预选，**不代表已授权发送**。用户仍必须检查接收方、模型和资料列表，然后勾选同意并手动执行。
2. 已选择资料时，在任务起始页可直接进入授权核对；仍能通过“调整资料范围”进入选择页。对没有选中资料的任务保留原先选择步骤。
3. 资料选择页用任务文字的有限连续字符与资料标题、文件夹名称进行**本机候选匹配**，最多建议六条，用户点击后才会加入资料清单；候选不读取正文、不自动授权、不扩大最多 30 条的限制。这是轻量标题匹配，不是语义检索或 AI 自动选取。
4. 授权核对页默认提供每条资料的标题和字数，完整正文可以按条展开，避免大量文档直接撑满手机屏幕。授权说明明确表达按需读取完整正文的范围。
5. 运行中点按关闭、返回或遮罩关闭时弹出确认框，避免无提示取消长任务。主动退出会继续沿用原本的中止边界。
6. 运行进度显著提示当前版本仅支持前台执行，切到后台会停止本次任务。保留阶段、耗时、已读取数及可展开的核验详情。**不宣称已实现后台持续运行或恢复。**

## 保留的安全条件

不读取未授权资料，不读取加密资料，不自动修改原文，不绕过发送预览与确认，不放宽深度复核和草稿保存限制；不改 Rust Agent 的取消与本机核验状态机。

## 测试与验收

CI 必须运行 Rust 源生成器测试、生成 Android 源代码、JVM 测试、Lint 和正式签名 APK 构建。安卓真机还需覆盖：由知识页与普通入口发起任务，空选择与已有选择，推荐资料的手动加入，30 条上限，长正文折叠与展开，未授权不能执行，运行时关闭确认、切后台中断、任务失败后的草稿保护与保存成功。
