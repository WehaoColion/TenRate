# Android 2.23.4.14 启动加载过渡界面优化

本次只调整 Android 冷启动期间的临时工作台占位界面，不修改计时、便签、知识、风控四个功能模块的真实页面，不修改 Rust 数据恢复、数据验证、同步或写入规则。

启动后立即显示简洁的工作台轮廓。使用随内容自适应高度的浅色状态面板替代占满剩余高度的灰色卡片，去除临时导航按钮及其虚假的切换状态。加载期间以不确定进度指示告知正在恢复本机数据，准备完成后进入真实工作台。修复第四个静态栏目名称为“风控”，补充英文界面翻译。

通过 Rust 生成器测试确保首帧不等待数据恢复、初始化前不读取默认 AppData 或触发写入操作。GitHub Actions 的签名 APK 构建通过后，使用 Android API 35 模拟器启动应用，并检查首次进入与强制停止后再次进入、UI 可见性和运行时致命异常。

此文档为候选说明；实际构建及模拟器测试状态以对应 GitHub Actions 运行结果为准。
