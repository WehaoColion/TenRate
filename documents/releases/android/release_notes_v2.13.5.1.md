# Android 2.13.5.1 客户推荐网络紧凑树状布局

版本：2.13.5.1（候选版本）  
变更范围：仅 Android 客户网络画布的主动层级排布与关系线显示。

## 问题

原“按推荐层级排列客户”把全部客户按照层级映射到固定横轴，再按相同层级的全局序号分行。不同推荐网络交织，同一个推荐人的直接下级不能保持紧凑，连线常呈斜线并制造错误的层次感。

## 改进

使用独立的 Rust 排布模块先计算有效推荐关系森林，再按固定的父子层级、同级兄弟连续排列与父节点居中原则计算子树宽度和卡片位置。独立推荐网络按宽度优先紧凑成行，超过目标宽度再换行；没有推荐关系的客户紧凑归置在已连接网络下方，不再夹在推荐链之间。普通便签和知识页面保留原有位置，推荐关系以外的自由连线不影响树形排序。

推荐关系位于明确的上下层时，使用从父节点底部到子节点顶部的正交折线；任意方向的普通连接继续使用原直线及箭头。只在用户点击“按推荐层级排列客户”时运行，单次操作可撤销，重复执行应保持稳定，不改变已有持久化结构和账户数据。

## 验收要求

Rust 域逻辑检验：父子深度、同级对齐、多个网络分组、孤立客户归置、卡片无重叠、普通便签不移动、重复排布一致、撤销完整恢复；现有自由连线与兼容测试保持通过。

GitHub Android signed APK 流水线编译原有 Rust 和 Android 代码，生成正式签名候选 APK。Android API 35 模拟器启动并安装该版本 APK，依次进入画布、新建客户、建立推荐关系、主动执行层级排布、截图、重启验证数据仍然存在。只有实际对应工作流成功后才可宣布构建和模拟器验收通过。
