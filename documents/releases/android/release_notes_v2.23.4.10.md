# Android 2.23.4.10 首页顶部信息区视觉调整候选

## 本次调整

在 2.23.4.9 已经保持单行的基础上，进一步收敛顶部标签的宽度与视觉强调。改动由 Rust 源码生成器对 Android 计时主页完成，保留既有点击逻辑、归档状态与动态今日时长。

原来的版本与归档标签按 2:1 比例分配宽度，造成版本标签有大量空白，两个独立的圆形按钮也偏显眼。本次将标签按内容宽度展示，版本标签负责必要的自适应压缩，历史与主题形成固定尺寸的右侧紧凑操作区，并把标签与操作按钮统一为半径 14 dp 的柔和圆角矩形。版本徽标略强，归档标签和控制按钮更克制。

在手机窄屏上显示 `v` 加完整版本号，较宽内容区继续显示完整品牌和版本号；长版本字符串只在空间确实不足时省略。状态标签仍会在计时累计后动态显示「今日」时长，英文环境保留其既有本地化逻辑。

## 兼容性与验收

Android 候选版本为 2.23.4.10，versionCode 为 22340，仅递增第四段。Windows 版本、同步协议、归档数据与定时器业务行为不变。

新增和更新的 Rust 源生成器测试验证分组布局、文本胶囊尺寸约束、按钮标签与回调、不影响全局的圆形徽标默认形状、英语今日时长、窄屏标识与无歧义的源模板锚点。签名 APK、Gradle 测试与静态检查由 Android 工作流运行；Android 模拟器与真机还需要视觉及点击验收，不能仅依据编译成功认定所有字体与屏幕宽度无问题。

本轮 PR 从 2.23.4.9 的 PR 分支分出，须先合入前置改动或重新定基线，不能单独把 2.23.4.10 当作基于主分支的独立功能。
