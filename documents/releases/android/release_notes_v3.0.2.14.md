# Android 3.0.2.14 本地保存历史预检修复

旧真机诊断曾记录单次快照预检耗时 793 秒。历史快照缺少摘要时，原预检可能回退到遍历整个工作区的历史正文，期间持有 SQLite 写事务，后续保存也会等待同一把写锁。

普通写入和后台恢复副本刷新只读取历史版本索引，并继续核对当前快照、当前快照的隔离记录与 JSON 恢复文件。历史版本较新或当前快照需要恢复时阻止写入。缺少摘要的旧历史留给恢复流程处理。新页与编辑仍以 SQLite 提交回执为保存完成依据。

GitHub Actions 在 Android 35 模拟器安装签名 APK。验收从含 7200 条旧历史的工作区启动，在应用运行后加入一条缺少摘要的历史记录，再执行实际保存。探针要求保存命中当前快照预检，原历史记录仍在，并在强制停止后重新打开确认页面完整性。既有 SQLite 写锁竞争、恢复副本修复及编辑退出检查同时运行。
