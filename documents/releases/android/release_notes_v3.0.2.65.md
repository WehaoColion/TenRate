# Android 3.0.2.65 防止旧保存回执覆盖新输入并加强正文验收

3.0.2.63 API35百万行退出端到端验收9516ms，应用退出回执及导航日志均29ms；不能据此断言SQLite提交耗时9516ms。API36第36轮实际正文末尾缺3字符，仍不合格。新版本正文和标题输入事件立即失效旧保存代次及显示状态，自动保存从当前文本字段取正文，回调需再次核对完整捕获的编辑内容；不改变队列、写锁、版本与隐私规则。探针按完整单正文块相等验证数据库及可见字段，而非子串匹配，记录退出无障碍与SQLite观测耗时，保留原8秒门槛、原实际输入和强制重启。修订不能证明输入丢字或超时已经消除，需同SHA真实模拟器复验。

十万条宿主SQLite迁移门禁保留，Android生产分块迁移仍未完成。未合并。
