# Android 3.0.2.9 知识文件夹创建与保存反馈修订候选

保留正式签名、包名、同步格式及原有知识内容。文件夹及非根级页面创建恢复完整目录校验，普通根级页面保留快速创建。错误反馈区分未进入修改、目录校验失败、持久化失败；诊断仅记录固定阶段，不记录名称或标识。同一对话框重试沿用操作 ID。

验收：签名 APK 在 GitHub Android API 35 模拟器运行，保留原历史负载、SQLite 写入竞争、恢复副本和输入测试，并增加页面保存后创建根级、嵌套文件夹，强制停止后验证数据库中的类型、唯一性和父子关系。个人设备故障的具体触发条件尚待真实日志确认；不关闭存储与恢复保护。

### 3.0.2.9 候选补充修订

真实设备回报显示，包含旧历史资料时，根目录文件夹及嵌套页面仍可能在 Rust 的完整工作区校验前失败。改为在同一写锁内只提取目标目录祖先及必要旧文件夹元数据供 Rust 校验；新增节点后仅对该节点规范化，绝不使用简化视图覆盖原始资料。对旧资料中无关的循环引用或异常页面仍保留原样，当前目标及其祖先如不可写则继续拒绝创建。增加 Kotlin 领域规格测试；签名 APK 的实际验收覆盖同一快照下的连续创建与重启后的结构验证。
