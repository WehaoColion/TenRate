# Android 3.0.2.56 修复文档输入法自动纠错误判

本版进一步修正 Android 文档输入稳定性验收中的输入法自动纠错误判。

3.0.2.49 的 API 36 模拟器截图与无障碍树显示一级标题仍然存在，但 Gboard 将 `StableHeading` 自动改写为 `Stable heading`，造成探针按原字符串匹配时误报。3.0.2.55 虽改为自然短语，但仍依赖输入法保持字母文本不变，不能从类型层面阻止同类回归。

本版将标题、段落、连续输入、保存和退出标记统一改为数字，并新增 Rust 类型 `ImeStableMarker`。其构造函数在编译期拒绝空字符串、字母和符号，只有非空 ASCII 数字可以作为正文验收标记。文档输入探针与分享导出探针共用同一组标记。

签名前回归测试重放历史 CamelCase 和自然短语标记，验证它们无法进入正文验收路径，并检查文档输入与分享探针使用同一组数字标记。保留 Enter 后区块数量、标题和段落定位、SQLite 保存回执、8 秒时限、退出和进程重启后的正文完整性检查，不降低 API 35/36 模拟器压力规模。

最终结果以本版签名 APK 的真实模拟器测试为准。
