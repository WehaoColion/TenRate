# Android 2.13.5.9：多轮 AI 对话保留与整段知识页保存

## 核心改动

Android AI 问答现在将每轮成功回答追加到独立的本机存档。用户可以关闭问答窗口后重新进入，使用「历史」打开原有会话；「新对话」仅创建新会话，不清除旧记录。模型请求仍按最近 8 轮、24,000 字符构造上下文，完整本机对话不按此额度截断。

本机存档按工作区与账户范围隔离，使用 Android KeyStore AES-GCM 加密和 AtomicFile 原子写入。存档读取失败时阻止覆盖；新答案写入失败时展示答案和重试入口，并阻止关闭或开启新提问，以免静默丢失。

「保存整段对话为一个知识页」会把本次已完成的全部问答按顺序写入一个文档。以后继续追问并再次保存时，会追加到同一页面。首次创建的页面 ID 与会话 ID 一致，保存回执通过持久化提交确认，重复保存不会静默生成另一份。追加保留旧文档的已有块，不替换用户的编辑内容。保留既有的「单独保存本轮」，其保存也改为确认持久化成功后再进入页面。

## 边界与兼容性

历史文字和知识页面是不同的数据集合。只有用户主动点击整段保存，内容才会进入知识库。完整文字在本机加密保存，暂不跨设备同步对话存档；主动保存的知识页仍沿用现有同步逻辑。历史图片仅保留附件数量与当前会话仍有效的引用；不自动备份外部图片原件，图片需要手动再次选择。模型发送范围和工作区资料权限没有扩大。

本次仅改动 Android 生成链路与其版本元数据，Windows 不变。版本号 2.13.5.9，versionCode 22359，沿用原有签名与应用标识。

## 验收

应完成 Rust 源码生成、Android 构建与签名检查，并在 GitHub Actions Android 模拟器上安装正式 APK 启动应用。需验证至少三轮问答后的关闭恢复、8 轮以上历史、整段保存、再次追加、原始页面编辑保留、网络失败与本机写入失败。无可用 API 密钥的模拟器只能验证启动、界面可达和本地结构，不可冒充已验证远端模型多轮真实交互。
