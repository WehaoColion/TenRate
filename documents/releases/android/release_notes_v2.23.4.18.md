# Android v2.23.4.18：知识文档块拖动排序

## 交互
左侧六点手柄单击仍打开块操作菜单。手柄拖动触发排序，文本区域继续输入与滚动。进入拖动时收起软键盘，发生跨块移动时提供实时临时顺序与轻量动画、定位指示线和触觉提示。触及列表边缘时自动滚动，拖动取消恢复原位。

## 变更与数据
实现保存在 Rust 源码生成器中，生成的 Android Kotlin 不入库。仅松手且最终位置改变时，依据当前文本草稿 materializedTextBlocks 提交一次 recordChange，因此保留块 ID、附件引用、原本的撤销与正常保存链路，不改变同步格式。预览顺序只影响显示、不直接落盘。保留菜单上下移作为辅助通道。

## 验收
使用 GitHub Actions 的 Android 35 虚拟机安装对应提交的正式签名 APK，并由 Rust 编写的 adb 驱动实际启动软件、创建多文本块、拖动六点手柄、检查文字顺序、点击菜单、强制停止并重启验证持久性。完整截图、无障碍树和检查报告作为 Actions 工件。监控作业每 20 分钟检查签名构建和模拟器结果；成功自动正常退出，失败即停止并标注失败，最长运行时间受 GitHub Actions 任务限制。未获得两项成功结论时不得宣称模拟器验收通过。
