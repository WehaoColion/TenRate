# Android 2.23.2.35 知识页保存等待修复

更新时间：2026-10-15 15:36（北京时间）

## 排查与修改

针对知识页退出时偶发等待数分钟的问题，确认了三处会增加保存等待的代码路径。自动保存原先在取得数据库写锁之前进入不可取消区域；即使新编辑已经取消旧任务，旧任务仍会留在锁队列并执行写入。本版将不可取消保护收窄到取得锁后的实际提交，等待中的过期任务可以退出队列，已经开始的提交仍必须完整结束。

保存预检缓存失效时，原先会再次读取并解压历史快照。本版在同一个数据库事务中调用已有原生完整性校验，核对内容摘要、封装与版本信息；只有校验成功、数据库状态未变化且当前记录有效时，才跳过已验证历史的重复展开。原生不可用、损坏、不兼容版本、缺失当前记录或状态变化都回到原来的完整检查。隔离数据、主恢复文件、备用文件和未迁移的旧文件仍独立检查。

知识页返回成功后，原来的页面销毁回调还可能再次提交保存：第一次写入产生的更新时间和版本元数据使完整记录相等判断失效。本版在确认保存成功、界面与工作区仍有效后标记页面已完成退出，使销毁回调不再排入重复写入；失败和失效回调仍保留原保护。

本次不改变页面布局、退出动画、正文、历史保留规则和同步格式。写入失败、工作区变化等原有保存保护继续生效。完整镜像写入及隐私清理仍按原流程完成，没有用提前退出或提前显示成功掩盖等待。

这三处是通过源码追踪和确定性状态测试确认的问题。尚未取得用户这次慢保存时的设备日志，不能认定它们是该次事件的唯一原因，也不承诺所有存储条件下的固定保存时长。

Android候选版本2.23.2.35，versionCode22304，仅递增第四段。Windows正式版本保持1.1.0.7。
