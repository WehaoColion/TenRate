# Android 2.13.5.3：首页今日计时标签语义修复

## 问题

计时首页第二个顶部标签在今日累计时长大于零时显示“今日”时长，在零计时时退回“归档”。这是同一非交互信息标签复用不同业务概念的错误，容易被误认为可点击的归档入口；英文模式零时长时还会出现中文“归档”。

## 修复

仅通过 Rust Android 源码生成器修改计时首页顶部信息。零时长显示“今日 0分钟”，英文环境显示“Today 0m”；非零时长继续使用原有的中文紧凑时长和英文时长转换。保持第二个标签为只读信息，不伪装为新的归档入口；已有的计时卡片归档操作、历史按钮、主题按钮、颜色、布局、数据结构和同步协议不变。按原四段版本约定递增为 2.13.5.3，versionCode 为 22351。

## 验证计划

运行 Rust 生成器和产品身份测试，校验零时长下中英文分支不会回退为“归档”，同时确认非零时长仍由真实的 todayTotal 驱动。GitHub Actions 生成、签名和校验 APK 后，在 API 35 Pixel 模拟器全新数据环境下启动应用，保存真实首页截图、无障碍树和日志；应在同一顶部信息行看到完整版本标识和“今日 0分钟”，且标签不是可点击控件。实际模拟器通过前，不宣称运行验收完成。

此更新不修改 Windows、服务器、账户、同步协议、计时记录或用户数据。
