# Android 2.13.5.12：知识模块资料工作台拟物改版

版本：2.13.5.12（versionCode 22362）。基于 2.13.5.11。

## 改动范围

Android 知识模块的文件夹及纸张采用同一套材质规范。使用 Rust 源码生成器输出 Canvas 矢量图形，不加载额外纹理位图。文件夹具备前后片、折页、内外边缘与轻微光照；页面具备独立纸面、折角、浅色渐变和细线。深色模式单独匹配高对比的对象与背景颜色。

目录行、文档内嵌子项和目录头部使用统一的细边框、纸面、轻阴影及按压反馈。知识目录将位置、标题、子项计数和新建操作按实体资料柜的层级组织，根目录不重复绘制面包屑。主操作使用低饱和实体按键，次要操作使用同系描边按钮。知识首页的创建按钮、文档库入口色彩同时收束，不触及原最近编辑的隐私读取逻辑。

## 兼容性边界

保留目录排序、长按拖拽、返回历史、页面创建和转换、编辑器身份、加密与法律分析排除、保存与同步，以及客户收付款与风控账本隔离。其他 Android 模块、Windows 客户端和服务器不变。

## 强制验收

GitHub Actions 先进行 Rust 源码生成测试、Android 构建、JUnit、lint、原签名与 SHA256 校验，然后在 API 35 Pixel 6 模拟器中安装同一提交签名 APK。开启系统动画和中文界面后，启动应用、创建文件夹、进入管理/设置、访问法律排除入口、开关文件夹，收集 PNG、UI 层级和录屏。不能以 PR 创建或源码检查冒充模拟器通过。PR 保留未合并。
