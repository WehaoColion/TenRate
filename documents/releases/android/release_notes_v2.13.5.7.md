# Android 2.13.5.7：修复客户款项入口与旧金额录入

## 修复范围

本版本对 Android 知识模块中客户卡片的收付款界面进行可达性修复。客户详情增加明确的「收付款明细 · 记录款项与实际收款」按钮，点击客户的「编辑客户」以后，同样提供可直接进入的「＋ 详细记录每笔款项和收款」主操作，避免把入口隐藏在汇总表格区域。

恢复「新建客户」和「编辑客户」原有「已支付」「待支付」人民币金额输入。原历史金额为独立汇总，不自动伪造记录，也不会因为创建新的逐笔项目而被覆盖。建议新收款使用项目及逐笔收款，不重复录入历史汇总。

## 验收门槛

Android 版本号 `2.13.5.7`，版本代码 `22357`。必须在 GitHub Actions 的 Android API35 模拟器安装本版本签名 APK，验证真实版本号、客户创建表单原金额栏、编辑客户页面的逐笔收款入口、记录用途及地点后的显示，以及强制停止和重启后的记录完整性。该验收必须由真实 Android UI 操作完成，不用仅源码断言代替。

本 PR 不改变 Windows 客户端、不接入风控账本，也不触及已有客户推荐网络关系。
