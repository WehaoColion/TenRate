# Android 2.13.5.8：知识模块空间层级与操作质感优化

## 实现内容

仅调整 Android 知识模块的 UI：知识首页突出「新建页面」，将置顶、任务块、图片数量压缩为一行辅助信息，保留最新编辑的隐私安全预览以及回收站、文档库入口。目录、画布、关联检索和知识问答均不删减。

筛选控制合并为更紧凑、可换行的横向操作区。目录范围、类型和排序仍可独立选择，筛选后显示结果数量和「清除筛选」，保持原有状态与权限。目录子项背景减轻，原有完整展开、拖动排序和问题提示仍在。文档属性条将「已置顶」「已加密」显示为状态，而不伪装成重复的操作按钮；需要管理时仍点击「属性」。

通用画布的创建说明改为明确任务文案，客户网络仍只是可选模板。选中卡片后的「编辑」「自由连线」「绑定推荐」「管理连线」维持主操作，尺寸、颜色和移除放到较轻的「更多设置」视觉组。客户收付款明细入口和独立于风控账本的数据仍然保留。

## 版本和兼容性

Android 2.13.5.8，versionCode 22358。保持既有包名、正式签名、数据结构、同步协议、加密规则以及页面返回保存语义。Windows 不变。不包含未合并的独立动效 PR #84。

## 验收

GitHub Actions 基于同一提交完成 Rust 源码生成、领域测试、Android 正式版单元测试与 lint，生成并验证原证书签名 APK、SHA256 校验。随后 API 35 Pixel 模拟器安装同一构建产物，启动应用，进入知识目录，新建文件夹并捕获实际屏幕截图、无障碍树及报告。只有构建和模拟器两部分都成功才宣称模拟器验收。复杂编辑、长目录、客户收付款与实机账户同步还需独立回归。
