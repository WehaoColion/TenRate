# Android 2.23.4.1 候选版：知识文档一键创建同级副本

## 行为

文档右上角「···」菜单新增「创建副本」，位于「创建命名版本」之后。点击后先通过原有可靠保存路径提交当前编辑草稿，保存成功后由 Rust 在当前工作区原文档的父级目录下创建独立副本，并进入副本。根页面复制仍留在根级，旧版文件夹内的页面继续保留旧版文件夹投影。

副本标题自动追加「（副本）」，同一父级已存在同名页面时递增「（副本 2）」。复制子页面和嵌套文件夹的完整可访问子树，重新分配所有节点 ID，并重连新父子关系。原有文档、子文档及其编辑历史完全不改动。

## Rust 数据安全

复制通过既有 `knowledgeContainerAction` JNI 接口实施，动作 `duplicate_page` 的 `id` 参数是新根节点 ID，`parent_id` 参数是原文档 ID，实际目标父级由 Rust 根据当前可靠快照读取，客户端不传入可能过期的目录位置。保留原有 `persistImmediately`、`publishAfterDurable`、工作区校验和不可取消写入事务。

副本保留原有正文、块、图片及附件引用、标签和页面属性。清空复制对象的旧版本堆栈、修订快照以及历史时间戳，让新记录从当前时间独立产生；不复制置顶状态。复制涉及的子项如已加密、已锁定、身份冲突或旧版兼容身份不安全，整体拒绝。单次最多 500 个节点，防止不可控的写入量。副本原始附件保持共享引用，文件并不重复上传。

## 回归与验收

Rust 回归覆盖普通目录下同级复制、二级子页和三级子页 ID 重新映射、根级复制、重名序号、原文完全不变、来源 ID 冲突及锁定子页拒绝。Android 从菜单触发时必须先完成编辑器草稿保存，复制完成后才显示目标页面。需要进一步在真机上验证图片展示、长文档耗时、删除原件后的附件可用性和同步到 Windows 的完整性。

候选版为 `2.23.4.1`，版本代码 `22331`。无同步协议和文件格式变更，不自动合并或覆盖设备数据。
