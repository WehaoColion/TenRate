# 2.23.4.19：Android AI 问答阅读体验重构

## 变更范围

本次仅修改 Android 知识模块 AI 问答 UI 的 Rust 源码生成器以及 Android 版本标识与发布记录。AI 请求接口、模型配置、知识检索、图片读取限制、加密对话存储、知识页写入校验及 Agent 的授权边界不变。

## 页面结构

问答窗口改为铺满可用屏幕的阅读界面，取消原有 8dp 外间距、圆角弹窗和暗色遮罩。顶部为稳定的“返回、AI 问答、历史、新建、更多”工具区；“直接问 AI / 问知识库 / 任务 Agent”移到紧凑的模式菜单。历史对话拥有独立列表，打开历史后隐藏当前会话输入框，选中记录再返回对话。

底部采用紧凑输入框、加号选图及“发送”组合，不再常驻两处整段保存按钮和上下文技术说明。所选图片保留缩略图、独立移除及私密发送说明。整段对话归档、打开关联知识页、发送内容预览、模型设置收纳至“更多”；单次回答仍保留独立保存操作。输入为空、模型未配置、保存失败或请求正在进行时，发送继续遵循原有守卫。

在向上浏览历史回答时，不再强行跟随新回复；提供“回到最新回复”入口。对话自动加密保存，本次改版不新增第二份聊天档案。

## 版本与发布

遵循此前审查结论，从 2.13.5.13 的构建号 22363 升级到 2.23.4.19，versionCode 22364。此前 2.13.5.x 的真实签名历史与发布条目一律保留，不改文件名或签名。

## 模拟器验收

GitHub Actions 在本分支先构建签名 APK，并使用相同提交的正式 APK 在 Android API 35 模拟器执行。Rust 驱动的 UI 验收检查打开问答、空态发送保护、历史独立显示、返回对话、“更多”归档入口及新对话的关键业务状态，留存截图和 accessibility XML。

由于 CI 不持有用户的模型服务密钥，本次验收不代表已经验证真实多轮推理或远端请求。
