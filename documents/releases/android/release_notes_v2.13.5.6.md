# Android 2.13.5.6：客户款项与逐笔收款明细

## 功能范围

安卓知识模块的客户网络画布可在客户详情的收付款摘要处点击进入专属明细页。每个客户可建立多个应收款项项目，填写名称、应付总额、服务地点、预计付款日期和项目说明；在每个项目下独立登记实际收款，记录金额、实际收款日期、实际收款地点、方式和备注。

款项可分次支付，已支付和待支付会按照各项目的累计实收与未收自动变化；支持编辑款项、修改收款、移除错误收款。删除已经产生收款的项目必须先明确处理收款记录，避免隐藏遗漏。

## 兼容与边界

旧版客户 `paidCents` / `pendingCents` 仍原样保留为「历史汇总」，显示时与新项目金额合计，但不会被伪装为有具体时间、用途和地点的记录。未填写的旧客户金额保持未填写状态。历史汇总只有原本有该记录的客户才会在编辑客户中显示调整字段。

全部金额依然由 Rust 以整数分解析、校验、持久化。款项和收款绑定到客户卡片，不参与风控账本的账户、流水或报表；普通便签及知识页面不能携带客户金额。保存失败、超额收款、无效日期、超出限制、重复提交、旧数据重开、撤销等由 Rust 域层规则保护。

仅调整 Android 端和 Rust 安卓画布持久化与源码生成文件。Windows 客户端、同步服务的产品身份和财务模块没有更改。签名仍须使用项目原有证书。
