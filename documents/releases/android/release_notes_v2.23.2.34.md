# Android 2.23.2.34 知识目录拖动排序

更新时间：2026-10-15 03:15（北京时间）

## 调整

知识模块的目录支持同一层级的页面与文件夹拖动排序。通过右侧手柄开始拖动，预览位置后松手保存；普通点按仍用于进入页面或文件夹。根目录、各层子目录分别保留顺序，长目录可在边缘继续滚动。

手动顺序独立保存在安卓版当前工作区，仅用于目录显示。不会改动首页的日期分组、标题排序、置顶与筛选规则，也不会改变页面正文、创建时间、更新时间、历史版本或共用同步数据。重新打开目录可继续使用本机顺序，新子项追加，已删除或移走的项目从投影中过滤。本次目录顺序不跨设备同步。

拖动取消、返回、目录切换或工作区变化时停止操作；未改变位置不落盘。只读、加密及位置异常条目保留原保护，提交前按最新数据核对父级、兄弟集合与权限。读取或保存失败不会报成功，不覆盖已保存顺序。

Android候选版本2.23.2.34，versionCode22303，只递增第四段。Windows版本保持1.1.0.7。
