# Android 3.0.2.58 修复签名构建前的独立模拟器探针编译阻塞

3.0.2.57 对应推送工作流 46078951793 的 release 作业 140773274366 在独立编译保存探针时失败：运行时分块输入与编译期标记位于同一模块，保存探针不使用固定标记，触发 -D dead-code；正文探针则可能出现相反问题。

本版将固定标记和运行时分块输入拆为职责独立的 Rust 模块，共用 ASCII 数字谓词。保存探针仅加载分块模块，正文和分享探针沿用固定标记。历史错误回放核对各自的模块依赖；既有数字完整性、分块校验、50万/100万历史、保存时限和 API35/36 模拟器门禁保持不变，未禁用任何编译警告。

本版是源码候选，尚未取得新的签名 APK 或实际模拟器验收结果。Word 内置阅读编辑与 PDF 转换、长期存储膨胀仍待实现和验证。
