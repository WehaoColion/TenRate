# Android 2.23.2.36 知识页保存失败修复

更新时间：2026-10-17 01:13（北京时间）

## 排查结果

用户截图中的“保存失败，笔记仍留在编辑页”原先将多种失败原因合并显示，无法仅凭截图确认具体失败阶段。本次源码排查确认两处能够导致保存失败的路径，并针对这些路径修复。用户补充重试仍失败，暂无手机诊断日志，不能把本次事件只归因于短暂队列饱和，也不能认定上述路径是截图事件的唯一原因。

资料库将整个工作区的当前快照保存在 SQLite 的 `app_data_json` 中。保存前检查、当前记录回读及部分恢复副本检查仍把整列装入 Android 的 CursorWindow。快照超过系统窗口容量时，读取可能抛出数据库异常，从而阻止后续保存。新版让游标只承载小型元数据，快照正文按128 KiB字节块读取，最后统一解码，避免跨块的中文和表情损坏。活动资料库在同一事务中固定记录身份；缺失记录、短读及不符的长度仍明确失败。摘要、封装、版本及未来格式保护继续生效，不迁移数据格式、不删历史记录。

保存控制器原先使用容量有限的队列并立即尝试投递；队列满时，退出所需的显式保存会直接收到失败。新版保留有界队列，独立发送协程等待可用位置，保持接受顺序；相邻且未开始的同页自动保存仍合并。关闭服务先禁止新请求，再等待此前已接受请求和最后刷盘。取消、未交付和真实存储失败均返回失败，不能凭排队成功关闭编辑页。

知识页改为保留本次保存的具体失败结果，只有最新有效保存回执可以更新提示。手机空间不足、数据库写入失败、工作区切换、保护状态变化和版本不兼容分别显示；诊断日志只追加失败枚举类别，不输出正文、密钥或工作区内容。失败时仍留在编辑页，原草稿保护保留。
