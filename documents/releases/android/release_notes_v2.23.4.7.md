# Android 2.23.4.7 移动目标常用位置候选

## 变化范围

仅调整安卓端知识目录“移动到”弹窗，不改变 Windows、同步协议及知识页面持久化结构。版本号按第四段递增为 2.23.4.7。

“常用位置”按成功移动的频次和最近使用程度综合排序，优先呈现最多五个目标；“最近使用”补充未入选常用位置的最近三个目标；剩余目标仍在“全部位置”，搜索继续覆盖全部合法目标。首次使用尚无历史时直接显示原有合法目标，不预设推荐。

移动历史按工作区隔离，使用稳定的节点标识，保存在设备本地私有 SharedPreferences 中，不随知识库同步，最多保留 64 条记录。只有在 Rust 知识层级移动已成功持久化且回调仍属于当前工作区时才增加次数；取消、选择位置、失败均不计入。

对每次打开的弹窗，从现有知识层级索引提取候选，过滤当前父级、不可写位置、自身及后代；动态排序不绕过原有“能否移动”校验。目录删除、加密或不可达后不能因历史记录而重新变为合法目标。原有保存中提示、位置变化重校验和失败反馈保持不变。

## 验收范围

源代码生成器增加频率排序及最近使用的 JVM 单元测试，覆盖次数与近期权重、长期未使用位置、知识目录根级、稳定 ID 及未来时间边界。Rust 侧增加生成器断言，确认工作区哈希键、有限历史条数及纯元数据存储。

手工验收需确认：同一目标连续成功移动后进入常用位置，其他工作区无此记录；重启后仍保留顺序；取消或失败不增加次数；搜索可以找到全部合法目标；被删、加锁、父级变化或成为自身后代的目标不能执行移动；英文界面可显示新增分组的英文翻译。真机或模拟器手工测试与正式签名 APK 构建结果以 CI/后续验收为准。

## 兼容与回退

没有迁移已有笔记结构或修改账户数据。回退至旧版客户端时移动历史留在本地而不影响旧版行为，原始文件与目录位置不受该缓存影响。
