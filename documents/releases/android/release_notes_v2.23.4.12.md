# Android 2.23.4.12 画布移动闪烁修复候选

## 原因

Android 知识画布手势结束时，旧前台 busy 状态导致工具栏禁用、更多按钮切换为进度圈。卡片拖动时连续切换选中工具栏，使画布高度发生变化；保存回执与旧拖动增量并存的帧可能让卡片瞬间跳位。

## 处理

Rust 生成的安卓 UI 区分静默手势落盘和显式编辑，保留 Rust 后台原子持久化、账户隔离、失败处理和写入互斥。拖动卡片使用绝对世界坐标作为预览，回执后的偏移自动归零；拖动中不改变选择工具条，顶部返回、更多、新建及缩放操作保持视觉稳定。

## 验证

Rust 源生成器测试与产品身份、JVM 画布测试覆盖行为回归。GitHub Actions 额外在正式签名 APK 构建前用 Rust 编译模拟器探针，构建后安装同一提交签名 APK 到 Android API 35 Pixel 模拟器，启动真实应用并进入“知识→Canvas”，在画布上执行三次真实 ADB 手势，录屏并用 Rust 分析顶部固定操作区变化；保存截图、UI 层级与 MP4，无法进入画布则不报告通过。

Windows、同步协议、画布 JSON 格式不变。Android 版本 2.23.4.12 / versionCode 22342。该候选替代尚未完成模拟器验收的 2.23.4.11。
