# Android 3.0：画布问答全屏阅读与可追溯回答

状态：PR 候选版本，必须以 GitHub Actions 的签名构建、Android API 35 模拟器证据为验收依据。未完成时不得宣称通过。

## 主要变更

画布问答由占用屏幕约 78% 的底部弹窗改为沉浸式全屏阅读工作台，保留顶端返回画布与必要上下文，把范围和隐私提示收纳为可按需展开的区域，回答正文获得独立滚动空间。底部改为紧凑的单行可扩展问题输入框和发送按钮；空状态给出可点击的画布相关问题。长对话可返回最新回答。

未发送的提问草稿以及当前阅读位置保留在画布页面生命周期中。点选答案来源定位卡片后，回到问答不会要求重新输入问题，也不会主动改写画布。历史仍使用既有账户和画布隔离的 Android Keystore AES-GCM 加密存储。

回答中依据编号与真实传给模型的资料顺序一致。[1] 可对应 Rust 本地精确汇总，后续编号对应可授权卡片与知识来源，不再将汇总来源与第一张卡片混淆。引用列表可定位到卡片，失效来源明确提示。旧版已加密的问答记录继续可读，不做格式迁移和清空。

对待收款金额相关提问，使用 Rust 只读画布查询所返回的精确人民币分数作为底层事实，在界面展示换算后的人民币元和待付款客户人数；面向用户的模型指令优先使用人民币元、两位小数，减少内部单位的干扰。原有收付款与风控账本隔离的约束不变。

## 版本与兼容性

Android versionName：3.0；versionCode：30000；正式签名 APK 名称：tenfold_v3.0.apk。沿用原有 Android applicationId 和签名证书以支持覆盖安装，不调整 Windows 版本、同步协议或现有知识数据格式。

## 验收

GitHub Actions 的 Android 正式版流程负责 Windows 构建机上的 Rust/Gradle 测试、签名校验和生成同提交 APK。独立 API 35 模拟器工作流必须安装该签名 APK，启动软件并检查画布入口、问答页面、空问题禁发、范围展开与收起、未发送草稿返回后保留、未配置 AI 服务时禁发及返回画布。保存模拟器截图和无障碍树。没有真实 AI 凭据时，不伪称完成模型在线调用验收。

## 设计边界

本次仅重构安卓画布问答，不替换通用画布和客户网络数据模型，不让模型改写画布，不上传加密或删除的知识页面。金额精确计算仍属于 Rust，Kotlin Compose 界面从 Rust 的源文件生成，不直接维护第二份 Android 页面源码。
