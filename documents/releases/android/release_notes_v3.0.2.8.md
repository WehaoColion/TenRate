# Android 3.0.2.8 知识页保存与编辑

知识文档向本地 SQLite 提交成功后，编辑器显示“本地已保存”。普通文本页新建和编辑复用已有快照格式，恢复副本在后台原子更新。后续提交会替代待写副本。工作区、数据库或副本发生变化时，后台任务重新核对写入条件。应用若在其间被强停，下次启动从已经提交的数据库快照恢复。

连续输入在停顿后生成保存用的正文，分享和导出按需读取当前草稿。普通文本修改复用已同步的其他段落输入状态，撤销、恢复版本和段落结构变化仍会重新核对。

候选验收使用同一提交生成的正式签名 APK，在 GitHub 的 Android 35 模拟器上检查数据库写锁、恢复副本无法写入、强停后重开，以及标题和段落输入。运行结果见对应提交的工作流。
