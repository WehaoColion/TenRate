# Android 2.23.4.8 知识画布可用性与本机备份安全候选

## 本轮调整

本轮仅修改 Android 客户端及其 Rust 源代码生成链路，不修改 Windows、同步协议、画布 JSON 版本或既有页面引用的结构。版本名 2.23.4.8、versionCode 22338，严格只递增第四段。

### 卡片放置

Rust 画布核心为新便签与页面引用寻找距离当前视野中心最近、与已有卡片不重叠的位置。算法考虑混合卡片尺寸、间隙和世界坐标边界；确实无法安排时返回错误，不静默覆盖旧卡片。已有卡片的位置保持不变。新加入或从卡片列表选择的卡片若处在屏幕边缘，界面可临时调整视野使其更容易被看见。

### 大画布总览

增加「总览」入口，用卡片轮廓、连线和当前视口框呈现画布整体。点击总览中的位置以 100% 缩放跳到指定区域。如果「适应」所需缩放低于旧版本允许的 35%，改为打开总览，不再误以为缩小到 35% 就能完整显示所有卡片。总览本身不写入画布数据，也不放宽持久化缩放范围（仍为 35% 至 250%），保证旧版读取兼容。

### 本机数据备份

Rust 生成的 Android 自动备份、云端加密备份和设备迁移包含规则显式增加 `knowledge_canvases/`。旧数据仍沿用账户哈希目录、原有事务提交、备份恢复与防过期覆盖保护。这里增加的是 Android 系统备份覆盖，不是画布跨设备知识同步；系统是否实际备份与恢复取决于设备、账号、空间、加密能力和系统策略，不能将规则包含视为恢复成功的保证。

## 验证项

Rust 新增测试覆盖连续创建 80 张卡片互不重叠、原有卡片坐标不变、720 单位混合尺寸、接近世界坐标上下限仍能寻找合法位置。安卓源代码生成的 JVM 单测增加总览坐标正反变换、边界内显示、空画布有效比例。Rust 源生成器测试核验三个 Android 备份覆盖点，保留原有 Android 画布持久化和保存失败测试。

CI 必须验证 Rust 源代码生成器与产品版本测试、Android JVM 测试、Lint、正式签名 APK 和原签名证书一致性。通过编译不代表已完成手机触控验收。后续设备验收重点是连续增加 10/100 张卡片、长宽不等与大量连线、总览点按定位、保存期间返回、重启后保存状态、加密页面预览、自动备份与设备迁移的真实恢复过程。

## 边界与回退

未修改跨设备同步、取消的手势、撤销记录格式与 Windows 画布。删除整张画布仍不可撤销；系统备份增强不能替代单独的导出恢复机制。旧版客户端不认识新增的界面总览，但可以继续读取已有画布格式与视图缩放值。
