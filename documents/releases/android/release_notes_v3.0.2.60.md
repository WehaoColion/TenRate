# Android 3.0.2.60 新增无损历史分块编码基础及过期分享缓存清理

3.0.2.59 真机报告应用数据3.50GB、缓存235.17MB。双API真实2500轮固定长度编辑确认每次产生完整历史快照，已压缩历史仍线性增长，空闲页为0。现有90天/至少100条自动恢复历史规则不变。

新增Rust内容寻址分块编码：可重同步的变长分块、SHA-256内容标识、原始字节长度与独立行摘要、逐块校验及完整重建校验、缺失/篡改/乱序/过大/写入失败拒绝；2500轮中文固定长度正文且版本元数据变化的领域回放，测量相对旧逐行zlib逻辑字节，逐一恢复历史。此为存储编码基础，未接入实际SQLite写入、迁移、回收或备份，不能认为旧库缩小，测量结果以CI为准。

应用仅尝试清理超过七天且名称严格匹配的可重新生成知识分享PNG/HTML缓存，保护近期文件、链接、子目录、未知文件及持久化正文和附件。清理在后台初始化后或生成新分享时进行，避开SQLite写锁。仍需真机验证清理量、文件安全和用户体验。不得清空数据或卸载重装。

保留所有旧签名、实际API35/36、百万行、2500轮存储测量验收；Word编辑/PDF尚未实现。
