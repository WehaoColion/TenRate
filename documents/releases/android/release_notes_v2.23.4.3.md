# Android 2.23.4.3 知识页面重复打开进入不同视图修复

## 问题与范围

同一知识页面“个人系统”首次点击打开正文编辑器，返回后再次进入却显示独立目录管理界面。“个人系统”的三个子项并未发生变化，但不同打开路径留下了不同的目录状态，造成同一页面重复进入的体验不一致。

此次仅修正安卓端 Rust 源码生成的页面导航行为，不改动知识数据、存储快照、目录排序、同步协议和 Windows 客户端。

## 修复

目录管理状态 `hierarchyVisible` 原来按工作区记忆。部分导航路径在选定 `selectedNoteId` 时仍将目录模式保留为开启，返回正文后可能重新暴露旧目录位置。

从独立目录打开普通页面、从父页面内联子项打开页面、新建页面、文件夹转页面以及创建副本成功后，统一先关闭目录管理模式、清理目录位置，再选择正文页面。用户通过目录入口主动浏览文件夹、移动和排序时，不改变目录管理行为。

额外在文档选中状态恢复、受保护文档解锁后校正目录可见状态，避免双模式同时残留。仍保留 `rememberSaveable` 的正常目录旋转恢复能力，不删除本机目录排序缓存。

## 测试与验收

Rust 生成器回归测试覆盖目录点开页面、新建与转换页面进入正文、文件夹仍进入目录，以及已选中文档不得与目录管理模式共存。项目 CI 需继续执行 Rust 单测、完整源码生成、Android/JVM 测试和签名 APK 构建。

真机验收应验证：从目录打开“个人系统”，返回并重复打开，始终显示正文编辑界面；从正文内打开同级或子页面后返回再进仍一致；显式点击“目录”仍进入管理界面，文件夹、拖动排序和移动可用；新建、转换和复制后的页面进入正文；锁定页面解锁后也不跳回残留管理界面。还需检查快速返回、屏幕旋转、进程恢复、跨工作区切换和编辑中保存失败时不丢失草稿。

这次 PR 只提交修复与测试，不等同于完成手机端验收，也不直接合并主分支。

版本：Android `2.23.4.3`，`versionCode 22333`。
