# Android 2.23.4.3 知识页面进入与返回路径修复（PR #64 修订）

## 现象与复审
“个人系统”同一节点曾因正文与目录管理模式残留而显示不同界面。首次修复简单地一起清除了目录显示及父级位置，虽然统一了正文入口，却破坏了返回上下文。

## 修订方案
在 Rust 生成的 Android 知识工作区加入独立的返回历史，每层记录来源类型、来源文档 ID、目录模式以及原目录位置，所有记录仅属于界面状态。打开正文只改变视图，不删除返回目标。由目录进入正文时返回原目录，由父页面进入子页面时返回父页面；由父页面进入文件夹后，也可以通过返回操作恢复父页面。目录面包屑与编辑器触发的管理操作都考虑来源上下文。

创建、转换和复制页面时根据来源保存返回目标。受保护文档成功解锁后才加入正文导航；取消从子页面发起的解锁时撤回临时跳转。删除或加锁的来源页面不会被强行重新打开。移除前版按 Compose 选中状态异步清空目录位置的修复。

保留目录管理、拖动排序、权限检查和编辑前持久化屏障，不改变知识数据、快照或同步协议。本 PR 仍为 Android `2.23.4.3` 候选，versionCode 为 `22333`。

## 验证要求
Rust 源生成器补充导航来源和返回目标回归断言。GitHub CI 需运行 Rust 测试、生成源码、Android JVM 测试及正式签名 APK 构建。手机需验证目录→父页面→子页面逐级返回、多级文件夹返回、创建副本与转页面、受保护文档取消解锁，以及屏幕旋转、跨工作区与保存失败场景。没有真机结果前不宣称交互已完全验收。
