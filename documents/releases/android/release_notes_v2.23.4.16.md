# Android 2.23.4.16 通用画布恢复与客户网络可选模板

## 产品定位

画布始终是通用知识可视化空间，允许自由创建便签、引用和新建知识页面、绘制普通连线、调整卡片尺寸、删除关系、撤销与重做。客户网络是可选模板，不是默认用途或独立编辑器。

## 入口与交互

打开知识画布时先进入「我的画布」页面。用户可选择「空白画布」或「客户网络模板」建立新画布，也可打开已有画布。已有画布、旧便签和引用页面保留，未显式选择客户模板的画布均为通用画布。

画布操作区保持紧凑；「添加」优先呈现通用便签、新建页面、引用已有页面，客户网络模板中额外前置客户卡片。普通画布仍可通过「更多卡片：客户」增加客户，不强制任何用户只能使用某种类型。

点击任意卡片均可展开底部详情，使用自由连线、连线管理、放大缩小、调整颜色、移除卡片。普通卡片也可以连到客户卡片；只有客户卡片专门提供「绑定推荐」和「添加此客户推荐的人」。客户网络模板中亦允许所有普通内容。

原有空白画布呈现「从一个想法开始」及「添加第一张便签」，不会再误导用户添加客户。

## Rust 模型与兼容策略

Canvas 增加带默认值的 template，旧文件缺少该字段时默认为 blank，允许显式值 customer_network。存储版本不变，避免破坏旧账户工作区。CanvasSummary 同时返回模板，前端不会根据画布名称猜测类型。

Edge 增加可选 relation，新增普通线明确为 link，推荐线明确为 referral。历史无 relation 的两名客户之间连接延续 2.23.4.15 时代的推荐含义；其他历史连接为普通线。画布验证只对推荐关系实行单一直接上级与有向无环约束；普通连线可自由连接客户、便签和页面，不与正式推荐关系混淆。用户允许对同一对客户建立一条普通联系和一条推荐关系，显示和删除均按各自类型处理。

视图、位置、文本与引用保持原有持久化与撤销语义。红包计算、订单结算、跨设备客户记录同步不属于本次交付。

## 验收

Rust 测试覆盖普通连线、知识页面、卡片尺寸调整、移除连线与撤销、客户推荐关系约束、历史客户连线兼容、模板创建及旧画布反序列化。

GitHub Actions 运行签名 APK 构建以及 Android API 35 模拟器，安装真实应用，执行通用画布创建便签、UI 自由连线、连接管理、模板创建客户、下级推荐、树形排列与强制停止后重进验证，并输出截图、无障碍树和验收报告。只有对应提交的构建与模拟器都明确通过才能认定完全验收。
