# Android 2.23.2.56 便签打开直接编辑

## 现象与原因

已保存的 Markdown 便签在打开后，如果启用了 Markdown 且内容非空，便签界面原先将 `markdownPreview` 初始化为 true，自动显示渲染后的公式、标题和排版。用户必须额外点击“编辑原文”才能编辑。知识文档此前已改为默认编辑，而便签仍保持旧逻辑。

## 本版改动

Android 便签每次进入时，先显示可编辑的原文输入控件，不再根据内容是否为空或是否启用 Markdown 自动进入排版预览。预览状态使用页面局部 `remember(note.id)`，不保存为跨页面或跨重建的编辑器偏好。用户仍可通过“预览公式与排版”主动切换，之后可点击“编辑原文”返回。

保留富文本正文的现有可编辑控件、标题编辑、待办与附件操作；历史版本仍按既有只读规则展示，不伪装为可编辑版本。未改变正文序列化、自动保存与手动退出保存、草稿日志、加密、账户隔离、工作区和同步协议。

## 验证范围

Rust sourcegen 回归测试校验默认编辑状态、主动预览的按钮与渲染分支、正文输入组件、历史版本只读呈现，以及原始代码锚点漂移时拒绝静默替换。GitHub Actions 的源码生成、Android JVM 测试和正式签名构建以实际工作流结果为准。

候选版本 `2.23.2.56`，versionCode `22325`。此 PR 不直接合并，也不宣称未经实机验证的输入法弹出行为、预览性能或设备兼容性。

## 建议实机验收

分别打开带 Markdown 公式的旧便签、普通文本便签、新便签、富文本便签和加密解锁后的便签，确认进入编辑内容；主动切换预览并退出、再进入，确认再次显示编辑状态。确认历史版本仍为只读，返回、自动保存、恢复草稿和附件功能保持正常。
