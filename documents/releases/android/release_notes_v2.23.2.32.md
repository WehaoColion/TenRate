# Android 2.23.2.32 知识页位置修复

更新时间：2026-10-14 19:07（北京时间）

## 问题原因

多层知识目录使用document.knowledge.parentId表示真实上级，编辑器旧属性条却只读取folderId和旧文件夹列表，导致已在文件夹内的页面显示“不放文件夹”。旧属性弹窗也只提供旧文件夹，不能完整表示当前层级。旧标签具有点击回调，但没有真机触摸记录，不能据此断言用户所遇到的点击无响应一定由某个触摸事件缺失引起。

## 修改

删除属性条中重复且错误的旧文件夹标签，保留上方目录路径与移动操作。属性入口使用明确按钮；文档属性显示从知识目录到直属上级的完整路径，并用“更改位置”打开现有完整目录选择器。根级显示知识目录，父页面、新文件夹和旧文件夹使用同一层级索引。位置随当前记录更新，不再依赖编辑会话入口时的旧folderId。

缺失上级、无法访问、循环及编号冲突会保留异常提示；新建记录尚未进入索引时显示未载入，不会误报为根级。加密、只读、不支持的格式和冲突记录维持操作保护。真实草稿先保存再打开移动选择，保存失败保留原编辑器，切换工作区和退出转场继续拒绝旧回调。页面色调与正文内容保存机制不变。

保存交接后会从当前工作区的实时数据重新读取上级；移动选择器在页面位置、祖先链或权限改变后清空待提交目标，要求用户重新选择。提交时再次读取当前位置和权限，避免保存期间的跨端移动被旧选项覆盖。缺失父级和循环关系允许可写页面明确选择根级修复；只读或不支持编辑的页面仍受保护。
