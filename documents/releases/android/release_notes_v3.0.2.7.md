# Android 3.0.2.7 知识文档输入稳定与标题排版

本次仅调整安卓知识页面的文档块编辑交互，不修改存储协议、同步与风控模块。由 Rust 源码生成器产生 Android 编辑器变更。

普通文本块不再在用户输入时执行块位置动画。收紧正文块与拖动手柄的最低高度，正文和一级标题依其真实行高展开，保留用户明确输入的空段落。列表定位根据是否出现 Markdown 预览栏计算前置条目数量，避免新块聚焦时的偏移。

工具栏应用标题格式只更新当前块，保留其他块的选区和输入法编辑状态；在空块执行“插入一级标题”或“插入二级标题”时复用当前块，不附加空块。非空块仍可以在后方插入新标题。

验收使用 Android 35 GitHub Actions 模拟器与同一提交构建的签名 APK。模拟器需启动应用，创建知识页面，确认空块插入一级标题不增加块数量，标题后按 Enter 只新增一个正文块，普通同一行输入时页面位置稳定，并在强制停止后重新启动核对标题和正文持久化。须以工作流成功和实际证据为准，不能仅凭此说明认定验收通过。
