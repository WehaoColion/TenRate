# Android 2.13.5.13：画布智能问答与来源定位

## 本次范围

在知识画布视图底部增加常驻的“向这张画布提问”入口；卡片详情增加“询问这张卡片”。半屏问答支持当前画布、单张卡片和卡片所属关联网络范围，回答引用的节点可点按定位。临时聚焦只改变显示位置，不修改图数据或原有收付款记录。

新增 Rust 原生只读画布查询投影。金额由现有客户金额与逐笔收款逻辑以整数分精确聚合，区分有向推荐与普通连接；先按用户选定范围计算全量统计，再生成有限的卡片与关系证据。Android 继续复用原 AI 服务配置和模型请求，新增 canvas 类型的受约束问答模式。

不同画布、账户的对话历史按独立标识在本机 Android Keystore AES-GCM 加密存储；保存失败保留本轮未存档回答并提供重试，解密失败禁止覆盖旧记录。已加密、删除及不可读取的知识页不进入模型上下文。画布图片和视频不会被当成已解析的视觉证据。全部答案均不写入客户卡片或“风控”账本。

## 操作和边界

进入“知识 → 画布 → 任意画布”，点击底部输入栏，选择范围并输入问题。若 AI 服务未配置，界面会明确提示并禁用发送。模型输出的 [n] 来源编号按本轮证据映射为“定位来源”动作，点击后回到对应节点。画布内容发生变化时，历史回答显示快照提醒。

本机 Rust 计算不依赖模型来决定累计金额；大画布最多取 20 张优先卡片作为示例，同时全量统计仍覆盖本轮范围。若示例不足以支持具体枚举，应明确表示不完整。此版本暂不提供自动创建卡片、跨画布联查或由 AI 修改数据。

## 验收

CI 已配置同一提交的正式签名 APK 构建，以及 GitHub Actions API 35 x86_64 模拟器启动、点击画布问答入口、检查空问题禁发、返回画布及保留截图的流程。具体构建与模拟器结论以对应 GitHub Actions 运行结果为准，未成功前不视为通过。
