# Android 2.23.4.11 知识画布拖动闪烁修复候选

画布拖动结束，原保存过程会把整个界面置为 busy，顶部按钮瞬时变灰或切成进度圈。卡片移动时每帧刷新选中状态，引起底部工具区改变画布高度。卡片写入确认后可能短暂叠加旧位置和拖动偏移。

本次在 Rust 管理的安卓源码生成器中区分静默手势保存与普通操作提示，保留 Rust 后端原子持久化和写入互斥。卡片保持世界坐标绝对预览，不随回执重复加位移；拖动时不更新选择工具区，避免布局闪动。

新增 JVM 回归测试覆盖普通保存可见、手势保存静默、并发写入被拒、坐标回执前后稳定。GitHub Actions 构建同一提交的签名 APK 后启动 Android 35 模拟器安装并打开应用，尝试进入画布，运行实际拖动并录屏检查固定操作区变化。无法进入画布或录屏不可用时应标记未验证，不得报告通过。真机 GPU 和高刷新率仍需后续复测。

Android 2.23.4.11 / versionCode 22341；不修改 Windows、同步协议和画布数据格式。
