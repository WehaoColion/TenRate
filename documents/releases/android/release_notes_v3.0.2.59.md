# Android 3.0.2.59 修复历史压缩任务提前退出并加入独立存储增长验收

既有压缩维护协程在切换工作区、进入恢复/禁止写状态或一次异常后退出，导致后续历史压缩停滞。现在仅在现有写锁、空闲窗口及同工作区认证回执均满足时运行；工作区变化时重置行游标，临时不可写时退避，异常后等待60秒并要求重新取得认证回执。不删除历史、不改变现有压缩格式或认证协议。

新增 API35/36 独立签名 APK 存储增长测量任务：固定16位正文，每轮只替换末位数字，真实输入、UI与SQLite精确保存回执，0/100/500/1000/2500轮和强制停止/重启后记录文件物理分配、数据库文件/WAL/SHM字节、SQLite页数/空闲页及各快照表逻辑字节。证据采集不计入单次8秒保存时限。任务失败时保留已采集样本。现有50万/100万及其他强制验收门禁不变。

该测试仅为固定长度正文场景，尚未覆盖所有存储增长来源、显式回收和附件；无真实结果之前不能认为存储膨胀已修复。未完成Word编辑和PDF转换。此版本尚需签名构建和模拟器验证。
