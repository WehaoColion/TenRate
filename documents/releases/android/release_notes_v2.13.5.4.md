# Android 2.13.5.4：知识模块动效统一与操作反馈

版本：2.13.5.4（versionCode 22352）

## 本次更新

Android 知识模块采用轻量、连贯的空间动效。知识目录行和文档内子项被按下时略微缩小，释放后恢复，沿用系统交互指示与触摸事件。文档内的子项展开、收起通过高度和透明度共同过渡，展开箭头同步旋转。

为了保证复杂知识库滚动流畅，只有不超过 24 个直接子项的容器才执行整组展开过渡，较长列表立即呈现。列表一开始就展开，不额外触发入场动画。收起中的子项禁止继续导航，避免视觉残影被误点。

目录拖动时提升悬浮层次和轻微尺度，邻近列表项重新排列从 140ms 调整为 190ms，保留原有长按拖动、自动滚动、无障碍上移下移、取消不保存和放下才持久化的规则。

进入知识文档时采用轻微向内的横向移动与淡入，返回目录时反向过渡。编辑器仍保留唯一的真实文档标识、原有返回栈、旧帧输入隔离及加密页面特殊处理，不因动画重新加载、修改正文或触发额外保存。

## 影响范围与兼容性

仅改变 Android 的 Rust 源码生成模块以及版本信息、验收流程与发布记录。不改 Windows 客户端、同步协议、知识文件格式、画布持久化、Agent 或风控数据。

此次采用一组克制的动效参数，目标是操作连续性而非复杂 3D 效果；Android 系统关闭动画时应保留功能状态，不依赖转场回调决定业务动作。

## 验收要求

先由 GitHub Actions 构建原正式证书签名 APK，运行 Rust 源码生成与领域检查、Android 测试和 lint。随后在 API 35 Pixel 模拟器安装同一提交的 APK，保持系统动画开启，真实启动应用、打开知识目录、创建文件夹，保存截图、UI 树及验收报告。

以上任务只有在对应 GitHub Actions 执行成功时才记为通过。候选 PR 未经明确指令不合并。
