# Android 3.0.2.55 隔离并提前编译安卓模拟器验收探针

本版收束模拟器验收工具的模块边界和编译门禁。

AI 对话探针与多语言导航探针不再共享一个含有互不使用函数的私有模块，分别使用职责单一的 Rust 辅助模块。签名 APK 生成前，GitHub Windows 构建任务逐个以 warnings-as-errors 模式编译知识动效、AI、多语言、知识保存和正文输入探针，避免在签名后才发现探针编译失败。

正文输入稳定性探针将标题测试标记从 CamelCase 改为带空格的自然短语，匹配 API 36 输入法实际保留的标题文本，避免把“# Stable heading”误报为标题丢失。

同时清理子页退出保存探针中已过期的工具栏返回注释，保留第二次 Android 系统返回的真实退出路径。
