# Android 2.23.2.41

版本号2.23.2.41，versionCode22310，承接实际已交付的2.23.2.40。Windows版本与正式文件保持原样。

## 问题与修复

2.23.2.40在DOM、公式和字体准备好后，直接绘制未挂载到窗口的WebView；没有等待网页实际绘制帧，也没有检查图片是否含可见内容。DOM完成与位图分配成功不足以证明正文已画进图片。用户反馈与这一缺陷吻合，尚未在其手机上复现确认。

保留离线Markdown与KaTeX公式排版，将临时WebView挂载到现有应用内容后方，不接受焦点和辅助功能访问。按实际正文尺寸布局，等待postVisualStateCallback返回，再在后续主线程任务中绘制。保留父容器生成的布局参数类型，防止尺寸更新时造成类型错误。

绘制结果按行检查像素。透明、纯白、纯色和只有单个杂点的帧不能被当成成功正文；不合格时回退StaticLayout文字绘制。检查在后台执行，不在主线程遍历长图。32MiB正文位图上限防止异常高度触发超大分配。

WebView阶段设8秒总超时，加载、公式检查或绘制回调不返回时仍可回退正文。正常、失败、超时、取消时移除临时视图并销毁WebView。排版失败的回退优先保留文字，无法保证回退图片中的公式仍保持数学排版。

Android官方说明区分DOM更新与实际绘制，并要求首帧保证所依赖的WebView挂载条件：[WebView.postVisualStateCallback](https://developer.android.com/reference/android/webkit/WebView#postVisualStateCallback(long,%20android.webkit.WebView.VisualStateCallback))。

## 本轮验证

执行真实Rust模板及受影响生成器模块的独立回归：65项通过。该范围不等于整个Rust仓库测试。

执行`python tools/verify_share_image_mutation.py`，实际Rust所有的导出帮助代码在Android 35 SDK与协程依赖下编译通过。4项领域测试覆盖透明与纯白帧、长图底部文字、纯色与单点杂噪、无效及超大尺寸。原始版本、注释变更、恢复版本均通过；移除空白拒绝和移除尺寸拒绝的两组变异均由指定业务断言失败捕获。运行时渲染器和安全端口在此项验证中仅作编译端口，未模拟手机或执行WebView绘制。

`git diff --check`通过。修改仅限Rust源码生成器、安卓版本与更新说明、验证工具；没有直接修改生成后的Kotlin。
