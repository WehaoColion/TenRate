# Android 2.13.5.10：知识目录操作层级优化

## 改动内容

知识目录浏览界面直接保留「新建子页面」和「新建子文件夹」。原本并列显示的「移动」「重命名」「转为页面／文件夹」与「查看与编辑正文」收进「管理」菜单。权限与数据库页面转换限制不变，仍保留只读、编号冲突与保存过程的禁用条件。

法律风险分析排除入口不再占据目录的普通操作区，而通过「知识设置」「文件夹设置」「页面设置」进入。排除和恢复仍需要原有的确认对话框，继承排除禁止解除的规则不变。工作区、目录顺序、页面与文件夹的存储结构均保持原样。

页面内部的子项操作区也采用相同的设置入口，避免单个功能出现两套明显不同的操作方式。本次不新增账户、同步或风控账本的数据写入。

版本：2.13.5.10。versionCode：22360。保持原应用标识及正式签名，支持覆盖安装。

## 验收

GitHub Actions 必须构建正式签名 APK，随后启动 API 35 模拟器并实际安装。Rust 驱动检查知识设置菜单、文件夹创建、管理操作默认收起、管理菜单中保留移动、重命名与转换，以及文件夹设置中法律风险排除入口可达。交互验收保存 PNG 截图和 Android 无障碍节点树。
