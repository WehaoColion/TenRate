# Android 2.23.4.6 integration candidate

本次整合从已发布主分支 Android 2.23.4.3 出发，合并 Android Agent 移动交互改进（PR #65）、AI 图片问答能力（PR #66）及英文界面漏译修复（PR #68）。不把仅有英文界面修复的旧版 2.23.4.3 安装包错误标为新版本。

## 主要变更

Agent：从知识页进入时预选当前页面，改善任务资料推荐与授权复核，运行中退出时明确提示取消范围。

图片问答：系统图库选择与预览最多 5 张图片，Rust 端校验图片格式和容量、接口视觉能力及纯文字兼容行为。

界面语言：英语系统下，本机默认计时任务名、动态计时摘要、时长和进度标签使用英文；补齐知识库、账务、账号和 AI 入口的部分英文词条。用户自建中文标题和备注不翻译。

## 版本和验证

正式候选版本名为 2.23.4.6，Android versionCode 为 22336，Rust 产品版本与 Gradle 一致。编译和正式签名交由 Android signed APK 工作流完成；必须以实际 GitHub Actions 结果判定，不以 PR 创建判定构建成功。

候选 APK 使用原签名证书，可在 GitHub Actions 中下载构建产物。GitHub Release 采用独立、不可覆盖的候选版本资产，只有校验成功才发布。

本变更不调整 Windows 客户端版本，不放宽本机保存和账号同步保护。真实设备外观、保存后重启及线上 AI 连接仍需单独验收。
