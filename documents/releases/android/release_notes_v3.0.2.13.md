# Android 3.0.2.13 知识页退出保存回执优化

在 3.0.2.12 基础上，自动保存的回执关联实际入队 epoch。仅在工作区、编辑代数、队列 epoch、完整 NoteEntry 一致且没有待处理显式保存时，复用已提交回执；否则继续原有持久化流程。加密路径不复用普通自动保存回执。

上版模拟器的超时界面树显示已返回知识首页，文档标题因列表虚拟化不在屏幕内；因此 9126ms 是探针超时，不是实际保存时长。新版要求知识首页的明确控件和应用成功回执，并保留 8 秒端到端上限，额外要求应用内部成功退出回执不超过 1500ms，强制结束进程后重开验证最终文本。签名 APK 与模拟器验收结果以本提交的 Actions 为准。

仍保留工作区快照格式；完整增量存储架构尚未迁移。
