# Android 3.0.2.51 模拟器验收探针修复

本版修正两个真实模拟器验收误判。

知识动效探针此前在帧耗时采样之前，先检查与动效无关的法律风险排除设置；该设置文案变化会提前终止动效验收。本版将探针收敛到知识目录可见性、文件夹创建、进入/返回/重新进入、录屏及独立帧耗时，不再以其他功能作为前置条件。

AI 对话探针此前只识别中文输入提示和图片入口。API 35 的真实截图及无障碍树已显示英语占位符 Enter a question 和 + Image，旧判断却将可见控件判为缺失。本版统一通过 Rust 文本谓词识别中文和英语标签，并在签名前回放上述历史失败。

本版不修改知识正文保存和队列持久化逻辑；最终动效与保存压力结果仍以本版签名 APK 的 GitHub 模拟器报告为准。
