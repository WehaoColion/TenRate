# Android 3.0.2.6 知识保存与草稿恢复

编辑器返回和加密便签锁定时，最终草稿检查点与本地提交进入同一保存队列。已解锁的加密内容会在接收保存动作时封装成密文，落盘在后台执行。保存预检的诊断在 SQLite 事务结束后写入，日志分别记录数据库锁等待、预检与提交耗时。

SQLite 原位更新历史索引。有效的旧历史快照由现有原生校验器逐条校验和压缩，处理进度保存在数据库里。旧记录的空封套标记继续保留，自动清理继续保护这些记录，恢复过程继续按原始内容和摘要校验。

签名候选包的 Android 35 验收从确认点击开始计时。测试恢复包含 7200 条旧历史的 v5 数据库，使保存预检缓存失效，并核对索引升级、保存数据在强制停止后可见、旧历史完整性及逐条校验继续推进。
