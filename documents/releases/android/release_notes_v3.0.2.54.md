# Android 3.0.2.54 修复子页退出保存压力测试的系统返回操作

本版修正知识子页面退出保存的 Android 模拟器探针。

此前探针第一次发送 KEYCODE_BACK 收起输入法后，错误地寻找编辑器内不存在的工具栏返回按钮；真实模拟器记录 back_sent=false，编辑器一直停留在屏幕上。因此 8984ms 的超时不能作为保存失败证据。

本版在确认编辑器仍为当前页面后，发送第二次 Android 系统返回键，真实触发离开编辑器，并继续核验父目录、正文内容和 SQLite 持久化回执。新增 Rust 状态策略回归测试，在签名前回放该错误。

本版不放宽 8 秒保存门槛、不减少 500000/1000000 条历史负载，也不更改产品保存逻辑。最终结果以本版签名 APK 在 API 35/36 模拟器上的实测为准。
