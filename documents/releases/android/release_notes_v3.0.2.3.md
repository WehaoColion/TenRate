# Android 3.0.2.3 便签首页修订

## 问题与成因

最近便签会按更新时间选取一条记录，其预览正文可能包含极长的连续段落。旧版顶部摘要 Text 未设置最大行数，并与三个操作按钮放在同一个垂直居中的 Row 中，因此长内容撑高卡片、按钮被推到正文中部，下方的便签列表与搜索被挤到首屏之外。

## 修订内容

在 Rust 源码生成链路中，只替换 Android 的 StickyNoteSummaryCard。最近便签标题、更新时间与两行正文摘要各自独立排版，正文使用 TextOverflow.Ellipsis；新建、文件夹、回收站放在独立 FlowRow 中，窄屏时自动换行。卡片保留已有圆角、纸张色、阴影和配色。

修订不截断原始便签数据、不改变 NativeOptimizerBridge 的摘要提取及任何便签存储、版本历史、加密或同步协议。完整正文仍从便签编辑页读取。

## 验收范围

在 GitHub Actions 使用原有签名 APK 构建与签名校验；API 35 模拟器从实际应用新建长便签，退出保存后检查首页摘要高度与操作按钮位置，截图及 UI 层级作为证据。小字号和大字号都应保障按钮可见。仅在 CI 明确通过时才宣称模拟器验收成功。

Android 版本名 3.0.2.3，versionCode 30005。Windows 版本与发布状态不变；该版本未经合并前仅为候选。
