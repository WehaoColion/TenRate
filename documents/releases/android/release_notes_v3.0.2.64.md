# Android 3.0.2.64 接通Android历史分块原生编码接口并降低目录绘制开销

3.0.2.63 同一SHA宿主十万条完整历史迁移、VACUUM、重开及逐条恢复通过，物理数据库2868232192→531374080字节，无丢失。生产Android历史写入尚未改格式；本版将Rust有界分块计划通过JNI暴露给现有Android原生验证器，独立核验历史行摘要、封签、表身份与版本，输出原始长度、摘要、有序分块长度和摘要，不复制原正文到返回计划。拒绝跨工作区封签、损坏、未来版本与空封签。新增领域回归，仍需生产SQLite事务、读取、备份、隐私清理及全量升级验收。
