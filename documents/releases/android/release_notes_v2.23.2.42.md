## 快捷操作面板

用户截图中，格子快捷操作标题距顶部只有4dp，并使用27sp加粗标题，文字贴近34dp圆角边缘。此次仅调整该面板：顶部内边距增加到16dp，左右20dp，标题改为22sp半粗体，顶部圆角24dp。右侧增加48dp关闭入口，复用既有触感、阴影和按压动效，辅助功能标签随语言变化。

面板高度限制为屏幕高度的86%，内容可以垂直滚动，适应小屏、横屏和大字体。任务名称、计时、分类与状态、记录数、已归档数，以及打开详情、查看历史、重置、归档行为保留。通用弹层默认34dp圆角及原有入场动效不变。

## 云端构建与签名

新增Windows GitHub Actions正式APK构建工作流，使用仓库现有四项Android签名Secrets。支持runner的NDK和Windows链接库路径，并缓存Rust依赖及编译输出。打包前检查密钥库证书，打包后使用apksigner验证APK，结束时清除签名配置和临时密钥库。不会上传签名材料。

Android源码生成器支持传入公开同步发现公钥，验证格式后推导发现主题。CI缺少公钥时停止构建，避免在临时构建机上生成新的同步服务身份。本地默认仍沿用原电脑的身份读取方式，构建不需要同步服务私钥。

同步配置来自用户提供的正式签名v2.23 APK，输入SHA256为`00b4289be8963a2f44d992a37b559319b0aa9582be3707948ab2232086927508`。已读取并核对实际DEX字段中的公钥、主题和启动入口，新包与该基线一致。未将旧启动入口的保留视为当前公网服务可用的证明。
