# Android 2.13.5.11：知识模块连贯动效与画布镜头

版本：2.13.5.11（versionCode 22361）。

## 范围与变化
仅更改安卓端知识模块的 Rust 源码生成器。文档切换保留真实编辑器身份与私密内容访问门禁，同时用短距离双向平移配合淡入淡出表达进入与退出。目录条目增加克制的按压缩放，简短子项列表可平滑展开、收拢，长目录避免整体布局反复重测。目录浏览根据层级深度以轻微横向位移入场，拖动中的卡片略微悬浮，其他条目短促归位。

画布将“程序触发的镜头跳转”与“手指直接操作”区分开来。选中远处卡片、适应画布、总览定位、应用缩放和低倍率小点定位均在模型确认后渐变视口；手指触摸立即取消进行中的镜头动画，直接跟手，不给拖拽添加人工延迟。继续保留现有拖动预览、后台单次提交、加密页面保护与客户收付款隔离。

## 验收方式
新增 GitHub Actions Android 35 Pixel 6 模拟器实测任务，安装与当前提交绑定的签名 APK，验证 SHA256、系统三项动画比例均为 1.0，再以 Rust 驱动完成真实的知识目录、文件夹创建、管理与设置交互。保存截图、Android UI 层级和可获取时的 MP4 录屏。GitHub 工作流构建通过不能代替实际观察录屏与帧率的结果。

## 未涉及
不更改 Windows 客户端、知识持久化、同步协议、文档正文、风控账本及客户金额逻辑。不合并旧版 PR #84，改动从最新主线独立重建。
