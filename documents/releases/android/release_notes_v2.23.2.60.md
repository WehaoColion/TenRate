# Android 2.23.2.60 - 减少同步中的历史附件检查

- 同步快照和附件哈希更新未移除现有附件引用时，不再对所有历史快照执行重复的附件清理扫描。
- 附件引用减少、新增删除标记、远端附件删除、工作区恢复或无法判断前后状态时，仍执行原有清理及历史快照保护。
- 原有本地保存、账户身份、同步协议、历史数据及附件保留规则不变。其他需要附件清理的操作继续执行清理；仅靠普通、无删除的同步不再回收先前遗留的孤儿文件。
- 新增附件扫描开始、返回和免扫描记录，便于区分实际等待阶段。
- 同时保留 2.23.2.58 的安全计时就绪和 2.23.2.59 的空白知识页退出优化。

GitHub 构建和签名通过后仍需真机验证。该优化针对日志指向的可疑等待环节，不能仅凭构建成功认定真实同步已经完成。
