# Android 2.23.2.46 启动路径优化

这是独立 PR 的候选版本，versionCode 为 22315，未合并前不视为已发布正式版本。

进程被系统清理后，重新进入会恢复本机工作区并校验保留的历史快照。历史数据量会影响启动等待；APK 或代码仓库大小不代表本机数据库大小。现有实现还在界面创建仓库时同步初始化原生校验库与本地认证密钥，并在每条历史快照认证时分配并复制一份完整消息。

本次将数据库辅助对象改为同步惰性创建，由后台恢复任务首次访问；Activity 在 Compose 首次构建前取得应用级共享仓库，提前启动恢复任务。Activity 重建仍复用同一实例，不新建恢复任务。压缩快照解码时预留认证域前缀，认证直接借用连续缓冲区，省去每行一次大块分配和复制。

所有历史仍逐条校验。认证仍由 ring 的 HMAC 校验接口完成，数据格式、认证域、密钥、摘要、账户与行标识、未来版本保护和丢失密钥时的完整恢复路径保持兼容。加载完成门槛仍保留，不提前开放默认数据的写入。未删除历史或引入跨启动的校验豁免。

本地 Linux 测试曾遇到现有非 Windows 分支的两个编译问题，测试时临时修正文件类型引用与备份标记常量的条件编译，随后恢复原文件；这些改动不包含在本 PR。云端继续使用项目既有 Windows 构建环境。

## 验证

运行原生快照编解码与校验回归、源码生成测试及产品版本一致性测试。签名 APK 工作流增加快照回归门槛，继续执行 Android 单元测试、静态检查和正式签名校验。本地主机快照相关 15 项回归与产品版本 2 项检查已通过。源码生成回归结果和云端构建状态见 PR。

主机认证微基准仅对比认证函数内的复制开销，不包含数据库读取、Base64 解码、界面绘制或设备性能，不能用于宣称手机启动提速比例。本机调试构建的 6 轮交替测试中，每轮认证 2000 条、每条 171820 字节，旧路径中位数 225104 微秒，新路径 214752 微秒；每轮省去 343640000 字节复制。该数字只用于确认消除复制开销，没有涵盖完整启动。

尚未连接用户手机，不能确认当前慢启动的各阶段占比或承诺秒开。真机验收应保留数据，分别测试 Home 返回、移除最近任务后重开、强制停止后重开和离线重开；记录 StartupLatency 的 snapshotPipeline、snapshotStream、ready、loadingGate 日志，并检查计时状态、便签草稿、账户切换和历史恢复。
