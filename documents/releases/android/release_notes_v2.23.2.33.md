# Android 2.23.2.33 知识页紧凑工具栏

更新时间：2026-10-14 22:01（北京时间）

## 调整

编辑页目录路径保持单行横向浏览，所有祖先位置仍可访问。子项数量、新建菜单和更多菜单集中在一行；子项列表默认收起，按需展开前三项和完整目录入口，取消重复空态行。

新建保留页面及文件夹；更多保留移动、重命名、页面与文件夹互转。属性、编辑原文与公式排版预览合并一行，窄屏可横滑。点按目标保持至少48dp，置顶和加密状态入口保留。完整目录浏览器沿用原有布局。

菜单继续遵循保存、工作区、退出转场、只读、加密、不支持格式和数据库类型保护。正文、附件、数据格式及Windows客户端不改动。

合并编辑工具行后同步核对正文的懒加载索引，避免插入或换行后滚动定位到工具栏。
