# Windows 1.1.0.8 源码候选

状态：源码候选，尚未正式发布或通过用户验收。Android 2.23.2.35 保持不变。

版本 1.1.0.8
更新时间：2026-10-16 01:37

知识模块增加完整目录窗口。页面中可以新建子页面和子文件夹，文件夹里继续建立多层内容；页面与文件夹转换保留正文和子项。移动时检查循环、锁定和过期目录，不允许把页面移进自己的后代。文档上方使用紧凑的路径、子项与操作入口，常用新建、移动、重命名、属性、转换和预览功能仍可使用。

目录支持同级拖动排序，顺序按本机工作区单独保存。首页继续按原来的更新时间与日期分组显示，目录排序不会改写正文、页面更新时间或首页卡片顺序。切换工作区、移动节点或目录成员变化后会重新核对拖动目标。

“我的”AI模块与知识页新增任务 Agent 入口，支持从知识页与便签选择资料，先查看问题、接收接口、模型、所选原文及调用上限，再明确授权发送。Agent 使用真实配置的远程模型，能够查找与读取本次选定资料、生成有来源的回答，并独立复核后在本机校验证据。不使用预存回答。进度显示当前阶段、已用时间、调用与工具计数、完成或失败状态；取消后停止后续步骤，已发出的请求仍可能计费。

Agent 结果先保留为待审草稿。只有复核通过、证据有效、资料及配置仍匹配当前工作区时才可保存为新的知识页；原记录不被覆盖。保存失败保留草稿，重复点击不会生成多份结果。切换工作区、密钥、接口或模型会使旧发送预览及结果失效。当前知识页还提供仅针对本页的 AI 入口，通用问答、知识库问答与任务 Agent 各自显示实际发送范围。

法律风险分析只读取当前可见版本及其中仍有效的附件，不再因历史版本残留而读取旧附件。报告“打开所属记录”按证据定位到实际知识页、便签、对应内容块、计时记录或财务逐笔记录；来源已删除或证据范围变化时明确提示，不回退为知识首页。历史计时记录按记录编号定位，不把同时间的其他记录当作原来源。

财务风控增加概览、核对与配置、账目和预测操作分区，减少长页面中寻找核对按钮的成本。金额继续使用精确到分的格式；核对凭据、资料不足时的待核对状态、缺失负债和安全金额判断沿用现有保守规则。

知识页和便签返回列表时，已修改正文通过现有后台保存线程写入，界面继续响应并显示保存进度，可选择留在此页。只有当前工作区、页面及编辑版本对应的保存回执成功后才退出；失败继续保留编辑内容，继续编辑后不会被旧回执带离页面。没有改动的页面直接退出，不因无关后台任务重新提交全文。数据库属性仍需通过合法性检查并确认保存才能退出。属性提交与历史前后导航保留既有同步保存屏障，较大属性变更的耗时仍需交互验收。

本次为 Windows 1.1.0.8 源码候选，补齐安卓近期目录、Agent、文档边界、证据跳转与保存流程。安卓版本仍为 2.23.2.35。本机正式 Windows 程序、同步服务及稳定桌面入口继续使用现有 1.1.0.7，待验收后按原发布流程统一更新。更新时间精确到分钟，本版说明可点按复制，旧版保留在历史版本入口。
