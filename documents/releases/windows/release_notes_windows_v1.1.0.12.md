# Windows 1.1.0.12：知识画布客户网络与收付款追赶（源码候选）

更新说明：1.1.0.12，Windows 原生 Rust 客户端功能追赶。继承此前 Windows 1.1.0.11 同步容量诊断，独立版本号递增，不改 Android APK、同步协议及正式安装清单。

## 新增能力

Windows 通用画布增加客户节点和可选客户网络模板，保留普通页面、便签与自由连线。客户卡片可查看姓名、备注、原始已付和待付人民币金额。金额使用与 Android 相同的 Rust 精确到整数分的解析及校验规则。

客户详情面板支持新增款项项目、服务地点、预计付款日期、实际收款日期、实际收款地点与方式。允许把原始金额一次性整理成款项和历史收款，保留总额、不重复计入。输入失败不改变已有款项。客户端所有客户款项仍仅归属于知识画布，不进入风控中的日账、收入、支出、资产和负债。

新增客户直接推荐关系与推荐层级自动排布，普通视觉连线不会自动当作推荐关系。同一被推荐客户最多只能拥有一位推荐人，拒绝成环。排列调用 Android 共享 Rust 布局，其他普通卡片保持原坐标。

画布缩放范围扩大至 1%～250%，低倍率不绘制密集正文，点击缩小后的节点可定位并返回正常阅读比例。

## AI 图片问答

Windows 的 AI 问答增加原生图片选择按钮，用户可主动选择最多 5 张 PNG、JPEG、WebP 或 GIF 图片，单张不超过 6 MiB，总量不超过 20 MiB。文件只读取到当前请求内存，图片指纹与问题、知识资料、模型和工作区绑定授权；确认发送时使用与 Android 一致的 Rust 多模态请求构造，不会自动上传整个资料库或本机附件。账户或模型切换会取消旧范围并清除待发图片。旧的纯文本请求保持兼容。

图片分析能力取决于实际所选服务商与视觉模型；未做真实 API 图像响应验收前，不能宣称所有模型均可看图。Windows 端原生文件对话框和图片签名拒绝边界需在 GitHub Windows 运行器上验证。

## 数据兼容和限制

旧 Windows 画布 JSON 没有 template、relation、paidCents、pendingCents、charges 时继续按默认值读取。原画布文件位置保持不变。本次只扩展 Windows 本机画布业务数据，不将 Windows 客户画布上传至 Android，也不更改服务器持久化协议。因此不能把新画布描述为已经实现跨设备客户同步。

Android 当前的本机法律分析排除规则不随此更新自动共享。Windows 端法律排除、跨设备画布同步与全部交互同等体验，需后续独立实现及验收，不在本次更新中假称已完成。

## 验收门槛

GitHub Windows 最新提交须通过 cargo check、客户端 Rust 测试、共享 Rust 测试、Windows 原生窗口启动与截图留证。正式候选编译完成后制作隔离的预览安装器和便携 ZIP，附 SHA256 校验。Windows 真机安装、真实账户、后台服务、公网入口及跨设备同步仍需独立验收，不以 CI 编译替代。

发布清单 release_artifacts/current/release_manifest.json 保持实际已核验的 Windows 1.1.0.10，直到正式安装、服务核验完成再更新。
