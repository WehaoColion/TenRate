# Windows 1.1.0.11 历史容量诊断与版本号校正（源码候选）

本次为 Windows Rust 同步服务历史配额诊断更新提供新的独立版本标识，修复此前 PR #60 与 Windows 1.1.0.10 共用版本号的问题。按项目版本规则，只将 Windows 第四段版本由 10 递增至 11，Android 版本、同步协议和账户数据库格式不变。

服务器历史容量拒绝响应现在可以提供压缩账户快照、历史媒体内容和引用元数据的分项占用、版本数量、媒体引用数量与本次预测增长量。当只读统计发生错误或与提交检查不一致时，仍使用原有容量拒绝提示，不会伪造诊断信息。历史保护、配额硬限制和同步的原子拒绝语义均未更改。

Windows 客户端标题、同步服务与守护程序目标文件名、内部发布身份、应用内更新记录、GitHub 预览工作流以及 Inno Setup 候选安装包统一使用 1.1.0.11。新增自动测试检查预览安装器、说明文件及工作流是否与 Rust 主版本号一致，防止再次使用旧版本名构建新候选包。

**状态说明：** 本条为源码候选的变更记录，不代表 Windows 稳定入口已经升级、同步服务已经部署或历史空间已被释放。正式版本清单 `release_artifacts/current/release_manifest.json` 继续如实指向此前核验过的 1.1.0.10。完成 Windows CI、候选安装包核验及实际服务部署验证后，才能更新正式清单。历史的无损增量编码和媒体引用去重属于后续独立工程。
