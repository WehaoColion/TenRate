# Windows 1.1.0.15：画布优先的桌面工作台

> 本候选基于 Windows 1.1.0.14 分支，依赖先行合并 1.1.0.13 与 1.1.0.14。本版本仅调整 Windows Rust 原生客户端的界面组织与反馈，不触碰 Android、账户、同步协议或财务数据格式。

## 调整内容

知识画布在常规桌面窗口优先获得内容宽度，左侧目录改为可随时打开的抽屉。顶部新增常显「目录」入口，客户推荐关系、推荐层级与自动排布、新客户画布等低频操作集中在「关系与排布」中，通用画布的卡片、连线、撤销、缩放和适应画布等高频操作保持可用。

风控的「保存」移到日常收支快捷栏，避免被顶部七个报表标签挤出首屏。总览、每日收支、月度资产、分类与目标保持常显，季度汇总、年度汇总与月度参数放入「更多报表」。原来的金额合法性限制和切换时待删除状态清理不变。

底部状态栏对完成的便签或文档导出结果进行模块限定：切换到其他模块后不再显示无关导出路径，但导出失败、只读、同步故障等错误仍持续显示。画布写入尚未完成时使用「待保存」，避免误将排队视为正在写盘。

发布身份和独立预览安装包增加到 1.1.0.15；正式 Windows 清单保持不变。

## 验收

使用 GitHub Windows 虚拟机编译 Rust 客户端并真实启动原生 GUI，在 1240×800 与 760×480 等尺寸下采集截图，执行 Windows 客户端和共享核心的 Rust 回归，生成 unsigned 预览安装器与便携 ZIP，并验证 SHA-256。该验收不冒充用户电脑上的覆盖安装、真实账户或跨设备同步测试。
