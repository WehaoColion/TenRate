# Windows 1.1.0.13 客户款项更正、画布总览与 AI 选图预览

版本：1.1.0.13，基于尚未合并的 Windows 1.1.0.12 PR #87 的独立增量候选。

## 实现范围

客户详情已经支持修改款项标题、应收总额、服务地点、到期日期和备注，补齐实际收款记录的修改金额、日期、地点、方式、备注。款项、收款删除必须先点击删除，再点击二次确认；已经存在收款的款项不提供删除入口，Rust 核心还会执行额外禁止校验。历史汇总整理仍然是转移而非新增金额。保存数据前使用 Android/Windows 共享的 Rust 原子操作与整数分验证，收款的金额不写入风控账本。

知识画布新增桌面空间总览，按内容边界缩放绘制卡片和连接，显示当前可见区域。点击总览中指定位置只改变画布视图中心，不移动任何客户节点；画布数据保存仍使用已有可靠持久化流程。

Windows AI 附图选择补上逐张移除与可解码的缩略图。在不增加额外编解码器和锁文件变动的前提下，当前缩略图只解码已有 Rust image 依赖支持的 PNG；JPEG、WebP、GIF 依旧按此前多模态格式校验接受并发送，但界面无法显示预览时展示明确提示和文件名。所有图片原始字节只在用户本次确认授权后发送，删除或替换图片会废止旧预览授权。

## 验收和风险

GitHub Windows 工作流需要在新分支上编译、运行共享核心测试、真实启动桌面窗口及截图，打包安装版与便携版并校验 SHA256。客户数据边界重点检验重复扣款、删除已有收款的款项、收款金额超过总额、日期越界、历史金额重分类、保存失败。1.1.0.12 的原有回归不可倒退。

未实现画布 Windows/Android 云端双向同步。Android Keystore 中的本机法律分析排除规则不会在 Windows 自动共享。100 天回收站自动清除、Windows 全语言翻译、正式证书签名和跨真实账户同步仍为后续工作。正式 release manifest 继续指向实际核验的 Windows 1.1.0.10，不用预览安装包冒充正式发布。

Windows 预览安装包应先备份真实资料，在隔离测试环境使用，不和正式 Windows 客户端同时编辑同一份工作区。
