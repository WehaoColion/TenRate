# Windows 1.1.0.14：画布事务安全与知识功能追赶

版本：1.1.0.14（Windows 未签名预览，仅对 Windows 端有效）。

本候选以 Windows 1.1.0.13 PR #88 为基线，#88 又依赖 #87。三项变更均未与正式主分支自动合并，不修改 Android 签名、APK、服务器通信协议或正式 Windows 发布清单。

## 代码修改

知识画布记录单调修订号，使用最多 32 组经过保存确认的本地快照支持撤销和重做。快速连续编辑按保存节流合并为一个可恢复状态，平移与缩放不会形成大量历史项。新保存操作预先核对文件的 SHA-256 指纹；发现其他窗口更改过原文件时拒绝覆盖并保留当前窗口未保存修改。历史状态只在本次窗口运行时保留，不构成替代系统备份的永久历史。这里的指纹检查是前置检查，不等价于跨进程或跨机器原子比较交换；跨设备同步仍未实现。

知识目录接入已存在的共享 Rust `duplicate_page` 操作：页面与完整有效子层级在原层级生成独立副本，原文和附件不被修改；存在编号冲突、加密或状态已变的记录不能被复制。

法律分析新增 Windows 当前工作区本机排除设置，知识根目录、指定页面或文件夹可选排除，并按目录关系继承。扫描准备时从当前资料快照移除符合条件的知识页面、解锁内容与附件，且在确认发送和后续模型调用前复查排除规则。排除规则读取失败、损坏、版本未知、准备期间变更均阻止沿用旧授权或继续扫描；未排除的便签、计时及风控记录原则上保持原扫描行为。策略不会自动从 Android 导入，也不上传到同步服务器。

## 安全与验收

CI 通过前不得将此版本称为正式发布。必须在 GitHub Windows 虚拟机上完成真实图形窗口启动、截图、全部 Windows 与共享 Rust 回归、Release 安装版和便携版打包、SHA-256 校验。对排除规则损坏、上级继承、断电恢复、同级副本和历史撤销编写关键行为测试。

本版本不包含跨设备画布同步，不对服务器运行自动清除或转换历史数据。正式发布或合并需先处理 PR #87、#88，再处理本 PR。正式安装仍需独立证书签名和实机覆盖安装、实际输入、真实账户测试。
