# 安卓客户网络收付款信息

本次仅改动安卓端客户卡片的收付款数据与显示。客户卡片增加可选的 paidCents 和 pendingCents 整数分字段，显示两位小数。两字段默认不存在，明确输入 0 才代表零元。允许最大 999999999.99 元，负数、指数和第三位小数由 Rust 服务拒绝，不进行浮点换算或四舍五入。

客户姓名与跟进备注仍然沿用原来的客户文本。旧画布文件没有新增字段时自动按空值兼容；编辑备注但未传金额字段时保留既有收付款金额。画布数据仍独立保存在 knowledge_canvases/<账户摘要>/canvases.json，未经风控模块的 FinanceProfile、dailyLedgers 等数据通路，不会自动生成收入、支出或资产记录。

编辑客户时金额是可选的文本输入。正常缩放的客户卡片显示两行金额，低于 35% 缩放优先保留名字；点击客户查看完整金额。客户推荐线、自动排布、其他卡片类型及通用画布功能均不改动。

验收重点：精确到分、空值与零值不同、旧卡片兼容、备注编辑不清空金额、撤销重做、错误金额失败不落盘、普通便签不接受客户金额。GitHub Actions 的 Android API 35 模拟器使用正式签名 APK，启动软件，创建带金额客户并截图核查金额、推荐关系与重启持久化。风控账本的数据模型保持原样。
