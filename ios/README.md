# TenRate iPhone 客户端 1.0.0.1

原生 SwiftUI 首版，最低 iOS 18；使用 Xcode 27、iOS 27 SDK 构建和模拟器检查。
复用现有 Rust app_data、计时投影、便签及财务精度校验源码，不复制算法。

支持：14 个计时格子、启停、短休息时间投影、分类、命名、历史记录、重置、归档及恢复；纯文本便签、新建/编辑/搜索/回收站/恢复；JSON 备份导出；深色模式、动态字体、系统安全区域。
磁盘写入在 actor 中串行执行，原子写入成功后才更新界面。损坏文件不自动重置。
加密、富文本、结构化文档禁止编辑，防止内容被降级。

尚未接入：账号登录、跨端同步、财务界面、AI、知识画布、附件和备份导入。
这是独立的本地首版，不代表 Android/Windows 的完整功能已经移植。
运行中的时间由持久化时间戳计算；系统挂起和杀进程后重新打开仍能计算，不宣称后台持续执行或响铃。

## 构建

macOS、Xcode 27、XcodeGen、Rust 1.95。执行 `bash ios/build.sh`。
GitHub Actions `iOS client` 自动安装工具、检查 Rust 业务流程、运行 iPhone 模拟器测试、构建 arm64 真机应用并打包。
Xcode 的营销版本为 `1.0.0`，构建号 `1`；产品展示与文件名为 `1.0.0.1`，遵循四段独立版本序列。

## 安装和签名

`TenRate-iOS-1.0.0.1-unsigned.ipa` 是真机架构的未签名应用，不能直接在 iPhone 点开安装。
需用自己的 Apple ID 经侧载工具重新签名，或提供有效 Apple 签名证书和包含目标设备的 provisioning profile 后生成签名包。
Android 的 keystore 不能签 iOS。不要在聊天、源码或 Releases 中公开证书私钥、密码或 Apple ID 凭据。
如需免电脑安装，后续接入 TestFlight 或正式分发，并完成 Apple 账号及签名配置。

构建流程将未签名包标为 GitHub 预发布，不会冒充正式可安装包。真机安装、通知、账户同步均须另行实测。
